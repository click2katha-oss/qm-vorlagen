## Pflegehinweise

- Pro Rechtsakt kann später eine eigene Datei `reg-00x-<kurzname>.md` entstehen, mit Artikelverweisen, Relevanz für das Unternehmen und Datum der letzten Prüfung.
- Nationale Vorschriften (Deutschland) und Änderungsverordnungen ergänzen, sobald geprüft.
- Jede Aufnahme mit Quelle (URL) und Prüfdatum versehen.
